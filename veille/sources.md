
# Sources de ma veille technologique

## Sujet
L'évolution du CSS dans le développement web moderne.

## Objectif
Suivre les évolutions du CSS, découvrir de nouvelles
fonctionnalités et comprendre leur utilité dans
le développement d'interfaces web.

## Agrégateur RSS
Feedly : https://feedly.com/

## Sources suivies

### 1. CSS-Tricks
https://css-tricks.com/feed/

Articles et tutoriels sur les techniques CSS.

### 2. web.dev
https://web.dev/blog

Actualités sur les technologies web et
les fonctionnalités des navigateurs.

### 3. Smashing Magazine
https://www.smashingmagazine.com/feed/

Articles sur le développement frontend,
le CSS et le responsive design.

## Méthode de veille
1. Consulter Feedly régulièrement.
2. Sélectionner les articles pertinents.
3. Vérifier les informations avec MDN.
4. Rédiger une courte synthèse.
5. Conserver les découvertes importantes.
6. Présenter les résultats dans mon portfolio.

## Fréquence
Consultation prévue : toutes les deux semaines.
