

# Sources de ma veille technologique

## 1. Sujet

L'évolution de la sécurité des applications web modernes.

Cette veille est réalisée dans le cadre de mon BTS SIO,
option SLAM.

## 2. Objectif

Suivre les évolutions de la sécurité des applications web,
notamment dans les domaines suivants :

- Cybersécurité applicative
- Sécurité back-end et API
- Intelligence artificielle
- DevSecOps et dépendances logicielles

L'objectif est de comprendre les enjeux techniques
et leur importance dans le développement logiciel.

## 3. Outil de recherche

ChatGPT, avec une recherche automatisée programmée
tous les 14 jours.

L'outil recherche des publications techniques et
propose trois sujets accompagnés de leurs sources.

La sélection et la validation restent personnelles.

## 4. Sources de référence

### OWASP

https://owasp.org/www-project-top-ten/

Référentiel des principales vulnérabilités
des applications web.

### CERT-FR / ANSSI

https://cert.cyber.gouv.fr/avis/

Avis officiels concernant les vulnérabilités,
les risques et les correctifs de sécurité.

### GitHub Advisory Database

https://github.com/advisories

Base de données des vulnérabilités connues
dans les bibliothèques et logiciels.

### Documentation PHP

https://www.php.net/

Informations officielles concernant PHP,
ses versions et ses mises à jour.

### Documentation Node.js

https://nodejs.org/

Actualités et informations officielles
sur l'environnement JavaScript côté serveur.

## 5. Méthode de veille

1. Recherche automatisée tous les 14 jours.
2. Proposition de trois actualités sourcées.
3. Consultation des sources originales.
4. Sélection du sujet le plus pertinent.
5. Étude des notions techniques.
6. Vérification de la compréhension.
7. Rédaction d'une synthèse personnelle.
8. Validation avant publication.
9. Intégration au portfolio.

## 6. Publications

Objectif : publier deux à trois fiches approfondies.

Chaque fiche doit contenir :

- Un titre et une date
- Les sources consultées
- Une présentation de l'actualité
- Une explication technique
- Les enjeux pour les développeurs
- Les connaissances acquises
- Une application pratique si pertinente

Aucune fiche ne sera publiée sans validation.

## 7. Traçabilité

Le fichier suivi-veille.md permet de conserver
l'historique des recherches, des sujets sélectionnés
et des validations.
