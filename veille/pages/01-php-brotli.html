PHP et Brotli : pourquoi surveiller les dépendances logicielles ?

Actualité : 26 octobre 2026
Consultation : 11 novembre 2026

L'actualité

Brotli est une bibliothèque qui permet de compresser et de décompresser des données, notamment pour réduire la quantité d'informations transférées sur Internet.

Une vulnérabilité identifiée sous le numéro CVE-2026-111497 concerne notamment Brotli 1.2.0. Elle peut provoquer des problèmes de sécurité lorsque des données compressées malveillantes sont décompressées.

Une version corrigée, Brotli 1.2.1, a été intégrée dans de nouvelles compilations Windows de PHP.

Ma vérification pratique

J'ai utilisé PowerShell pour examiner mon installation PHP sous XAMPP.

  • PHP : 8.3.36
  • cURL : 8.23.0
  • Brotli : 1.2.0

Cette vérification montre qu'une bibliothèque concernée par la vulnérabilité est présente dans mon environnement. Elle ne prouve pas qu'une application particulière est exploitable.

Ce que j'ai appris

J'ai compris qu'un code PHP correctement écrit peut utiliser des bibliothèques vulnérables. Il faut donc surveiller leurs versions, consulter les avis de sécurité et installer les correctifs adaptés.

J'ai également appris qu'une mise à jour doit être suivie de vérifications pour s'assurer que la version corrigée est réellement utilisée.
