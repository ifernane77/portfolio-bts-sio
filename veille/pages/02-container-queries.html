Container Queries

Date de consultation : 09/10/2026

Fonctionnement

Les Container Queries permettent d'adapter les styles d'un composant selon les dimensions de son conteneur. Elles complètent les Media Queries, qui permettent notamment de réagir à la largeur de la fenêtre.

Exemple de code

.zone-cartes {
    container-type: inline-size;
}

@container (min-width: 500px) {
    .carte {
        display: grid;
        grid-template-columns: 1fr 2fr;
    }
}

Intérêt pour mes projets

Cette fonctionnalité pourrait améliorer l'adaptation des cartes du portfolio ou de DoctoRDV selon l'espace disponible.

Bilan

J'ai identifié une technique pour créer des composants responsives plus autonomes. Un test pratique reste à effectuer.
