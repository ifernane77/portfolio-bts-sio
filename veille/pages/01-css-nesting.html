CSS Nesting

Date de consultation : 09/10/2026

Fonctionnement

CSS Nesting permet d'imbriquer des sélecteurs CSS au sein d'autres règles. Cette fonctionnalité est native au navigateur et ne nécessite pas de préprocesseur comme Sass.

Exemple de code

.carte {
    padding: 20px;

    &:hover {
        background-color: #eaf2ff;
    }
}

Intérêt pour mes projets

Cette syntaxe pourrait simplifier les styles des cartes de formation de Light of Knowledge ou de mon portfolio.

Bilan

Cette fonctionnalité permet de mieux organiser certaines règles CSS. Un test pratique reste à effectuer.
