Le sélecteur :has()

Date de consultation : 09/10/2026

Fonctionnement

La pseudo-classe CSS :has() permet de sélectionner un élément en fonction de la présence ou de l'état d'autres éléments qui lui sont associés.

Exemple de code

.formulaire:has(input:invalid) {
    border: 2px solid red;
}

Intérêt pour mes projets

Cette propriété pourrait améliorer les retours visuels des formulaires de DoctoRDV ou de Light of Knowledge.

Bilan

J'ai découvert une technique permettant d'adapter les styles CSS selon l'état des éléments d'un formulaire. Un test pratique reste à effectuer.
